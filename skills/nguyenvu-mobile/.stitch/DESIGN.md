# NGUYENVU Mobile Design System

## 1. Visual Identity
- **Brand Colors:**
  - Primary: `#D4AF37` (Metallic Gold) - For CTAs, active states, and highlights.
  - Background: `#0B0C10` (Deep Black) or `#121212` (Dark Charcoal).
  - Text: `#FFFFFF` (White) for primary, `#A0A0A0` (Light Gray) for secondary text.
  - Surface/Card Backgrounds: Semi-transparent dark (#1A1A1A with 60% opacity) for Glassmorphism.
- **Typography:**
  - Font Family: `Inter`, `Roboto`, or a modern sans-serif like `Outfit` combined with a sophisticated serif for headings if possible (e.g. `Cormorant Garamond` or `Playfair Display`). If limited to one font, use a clean, high-end sans-serif.

## 2. Global Styles
- **Glassmorphism:**
  - Background blur (`backdrop-filter: blur(12px)`).
  - Subtle borders: `1px solid rgba(255, 255, 255, 0.1)`.
- **Gradients:**
  - Subtle dark gradients on backgrounds to create depth.
- **Borders & Radii:**
  - `border-radius: 12px` for cards.
  - `border-radius: 8px` for buttons.
- **Shadows:**
  - Soft glowing drop shadows for gold elements.
  - Deep dark shadows to lift cards off the background.

## 3. UI Components
- **Buttons (CTAs):**
  - Primary: Gold background (`#D4AF37`), black text, bold, glowing hover effect.
  - Secondary/VIP: Glassmorphism background, gold border, white text.
- **Cards:**
  - Uniform layout, studio-quality image placeholders.
  - Minimalist text.
- **Navigation:**
  - Sticky header, blurred background.
  - Logo on left, navigation links center, icons/CTAs right.

## 6. Design System Notes for Stitch Generation
```markdown
**DESIGN SYSTEM INSTRUCTIONS:**
- Theme: Ultra-luxury, Dark mode.
- Background: `#0B0C10` or dark gradient with glassmorphism elements (`backdrop-filter: blur()`).
- Accent Color: `#D4AF37` (Gold) for buttons, borders, highlights.
- Typography: High-end sans-serif (e.g., Inter/Outfit). Headings can be serif if suitable.
- Components: Use glassmorphism for cards, headers, and floating elements. Ensure studio-quality aesthetics, minimalistic and clean layout.
- Imagery: Prefer 3D renders or high-quality product images of smartphones (iPhone, Samsung, Vertu) on dark backgrounds with subtle lighting.
```
